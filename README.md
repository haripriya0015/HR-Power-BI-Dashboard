# 👥 HR Attrition & Employee Performance Dashboard

## Overview

The HR Attrition & Employee Performance Dashboard is a Power BI solution designed to help organizations understand employee turnover patterns, workforce performance, and diversity metrics. The dashboard enables HR teams and business leaders to make data-driven decisions for employee retention and workforce planning.

Using employee records and HR datasets, the dashboard provides actionable insights into attrition trends, salary distribution, departmental performance, and workforce demographics.

---

## 🚀 Objectives

* Analyze employee attrition trends
* Identify high-risk turnover groups
* Monitor employee performance
* Evaluate salary and compensation patterns
* Track workforce diversity metrics
* Support HR decision-making with data-driven insights
